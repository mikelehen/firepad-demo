# demo.firepad.io backup site.

For some reason firepad.io disappeared, but the Firebase database is still alive. So if you had a pad at:
> https://demo.firepad.io/#[PADID]

You can now access it at:
> https://mikelehen.github.io/firepad-demo/#[PADID]

---

Sources for http://demo.firepad.io/

Although this is a gh-pages branch, we actually serve the site from Firebase
Hosting now, so to deploy the site, run:

    firebase deploy
